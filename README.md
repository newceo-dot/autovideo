# AI Video Maker (AI 영상 자동 제작기)

이 프로젝트는 실시간 뉴스 트렌드 분석 또는 블로그 원고를 기반으로 대본(시나리오), 고화질 이미지 생성(Imagen 3), 성우 TTS 내레이션 음성 합성을 한 번에 완성하는 웹 기반 자동화 솔루션입니다.

---

## 🚀 시작하기

이 프로그램은 **빌드가 필요 없는 단일 HTML 페이지**로 구성되어 있습니다. 복잡한 환경 설정이나 Node.js 설치가 없이도 손쉽게 사용할 수 있습니다.

### 방법 1: 직접 열기 (가장 간단함)
- `e:\ai-video-maker\index.html` 파일을 더블클릭하여 브라우저에서 실행합니다.

### 방법 2: 로컬 서버 구동 (권장)
오디오 합성 및 파일 내보내기 기능의 호환성을 극대화하기 위해 로컬 웹 서버에서 구동하는 것을 권장합니다.
- 폴더 내의 `run.bat` 파일을 더블클릭하여 실행합니다. (파이썬이 설치되어 있다면 자동으로 로컬 서버를 열어 띄워줍니다.)
- 또는 터미널을 열고 아래 명령어를 입력하여 서버를 직접 구동할 수도 있습니다:
  ```bash
  python -m http.server 8000
  ```
  이후 브라우저에서 `http://localhost:8000`에 접속합니다.

## 🔑 API 키 설정

프로젝트를 원활하게 구동하기 위해 아래 API 키가 필요합니다:

### 1. Google Gemini API 키 (필수)
이 서비스의 이미지 드로잉(Imagen 3) 및 대본 자동 작성을 지원합니다.
- [Google AI Studio](https://aistudio.google.com/app/apikey)에 접속하여 무료 API 키를 발급받을 수 있습니다.
- 앱 내 **3단계(설정 페이지)**에서 키를 한 번 입력하면 브라우저(`localStorage`)에 안전하게 자동 저장되어 이후 다시 입력할 필요가 없습니다.

### 2. Claude API 키 (선택)
대본 및 트렌드 도출 엔진을 Claude로 사용하고자 하는 경우에 필요합니다.
- [Anthropic Console](https://console.anthropic.com/)에서 키를 발급받을 수 있습니다.
- 브라우저의 CORS(교차 출처 자원 공유) 보안 정책으로 인해 직접 호출 시 차단될 수 있으므로, **CORS Proxy 주소**를 함께 기입하거나 CORS 해제 확장 프로그램 사용을 권장합니다.
- 기본적으로 **Gemini 2.0 Flash**를 대본 엔진으로 쓰시면 CORS 문제없이 빠르게 구동됩니다.

## 📋 핵심 기능
1. **실시간 트렌드 수집:** 구글 뉴스/검색 실시간 연동을 통한 최신 시사 및 유행 토픽 수집 (15개 리스트 추천)
2. **블로그 가공 변환:** 줄글 블로그 포스팅 원고를 유튜브 맞춤형 후킹 내레이션과 일러스트 시나리오로 변환
3. **엔진 선택화 및 저장:** Gemini(무설치/검색연동)와 Claude 중 선호하는 엔진 지정 가능
4. **고해상도 이미지 드로잉:** Imagen 3 모델을 활용하여 16:9 규격의 미학적인 일러스트 생성
5. **한국어 성우 TTS 오디오:** 브라우저 내장 다국어 보이스로 오디오 연속 테스트 재생 및 가시적인 주파수 파동 애니메이션 시각화
6. **추출 지원:** 완성된 시나리오 구조(JSON) 및 이미지 리소스 전체 다운로드 지원
